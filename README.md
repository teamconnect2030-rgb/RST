# ♞ RST — RAI Script Translator

**A Windows app that makes your Claude plan last longer.**
Type normally. RST picks the cheapest Claude model that can do the job, keeps each request small, and shows how much of your plan you have used.

## ⬇ Download

**[Download RST for Windows (RST-Setup.exe)](https://github.com/teamconnect2030-rgb/RST/releases/latest)**

Open the link, then under **Assets** click **`RST-Setup-x.y.z.exe`**.

## What you need

- Windows 10 or 11 (64-bit)
- The **Claude desktop app** or **Claude Code**, installed and **signed in to your own Claude account**.
  RST uses your own Claude plan. It does not have an account or a key of its own.

## Install

1. Run `RST-Setup-x.y.z.exe`.
2. Windows may show **"Windows protected your PC"**, because the app is not code-signed.
   Click **More info → Run anyway**.
3. Click **Install**, then **Finish**. RST appears on your Desktop and in the Start menu.
4. Optional: right-click RST in the taskbar and choose **Pin to taskbar**.

If RST says it cannot find Claude Code, open **⚙ Settings → Advanced** and browse to `claude.exe`.

## What it does

| Feature | What it means for you |
|---|---|
| Auto model | Haiku for quick questions, Sonnet for writing and code, Opus only for big jobs |
| Max Saver | A fresh, small session for each message, with a short note when you continue a topic |
| Answer cache | The same question asked again within 24 h is answered for $0 |
| Smart shrink | Removes filler words and collapses repeated log lines before sending |
| Usage bars | Your 5-hour and weekly plan usage in %: green below 70%, yellow to 85%, red above |
| Savings bar | How many tokens RST saved today |
| + Files | Attach text, code, images and PDFs, or drag them onto the window |
| Project mode | Point RST at a folder to let Claude work on its files |

Replies are in **Malayalam** by default. Change it in **⚙ Settings → Reply language** (English, or the language you write in).

## Privacy

RST runs on your PC and talks only to Claude, through your own Claude Code sign-in. Chat history and settings stay in `%APPDATA%\RST` on your computer.
